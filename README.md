# Tanışıyor muyuz?

Yeni insanlarla tanışırken buzları kırmak ve derinlemesine sohbetler başlatmak için tasarlanmış interaktif bir kart oyunu.

## Oyun Hakkında

Bu oyun 3 aşamadan oluşur:

1. **1. Aşama - Önyargını Kır** (Sarı/Turuncu tema)
   - Karşındaki kişi hakkında küçük tahminlerde bulun
   - 100 soru

2. **2. Aşama - Empati Kur** (Mor tema)
   - Sadece dinle, yorum yapma, yer aç
   - 150 soru

3. **3. Aşama - Diyalog Başlat** (Yeşil tema)
   - Sohbet kendiliğinden aksın, herkes dahil olsun
   - 150 soru

## Nasıl Oynanır?

1. Karta tıklayarak yeni bir soru görün
2. Soruyu sesli okuyun ve karşınızdaki kişiye sorun
3. Cevabı dinleyin ve sohbet edin
4. Hazır olduğunuzda sonraki soruya geçin
5. Level tamamlandığında "Sonraki Aşamaya Geç" butonuna tıklayın
6. Oyun loop şeklinde devam eder: 1 → 2 → 3 → 1 ...

## Özellikler

- Sorular her level'da rastgele karıştırılır
- Tüm sorular sorulana kadar tekrar etmez
- Alt kısımda kaç soru sorulduğu gösterilir
- Progress dots ile istediğiniz level'a atlayabilirsiniz

## Kart Türleri

- **Normal Sorular**: Standart tanışma soruları
- **Cesaret Kartı**: Aksiyon gerektiren eğlenceli görevler
- **Hatırlatma Kartı**: Oyun sırasında akılda tutulması gereken notlar

## Kullanım

Tek bir HTML dosyasıdır. Herhangi bir web tarayıcısında açabilirsiniz:

```bash
open index.html
```

Veya GitHub Pages üzerinden host edebilirsiniz.
